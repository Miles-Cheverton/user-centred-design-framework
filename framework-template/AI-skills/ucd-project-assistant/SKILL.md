# UCD project assistant

For project work, open the specified project’s `_project-config.md` first. Resolve its **Working folder** using the [project boundary rules](../ai-guidance.md#confirm-the-project-boundary). Use only that confirmed folder and specifically authorised external sources; never search other projects by filename or ID. If the folder is unclear, ask for its exact path or URL; a task limited to supplied files may continue within that set. Resolve links from the canonical project path `AI-skills/ucd-project-assistant/SKILL.md`, not the installed or copied skill location. Read the project’s `AI-skills/ai-guidance.md` [shared principles](../ai-guidance.md#shared-principles) and the applicable sections of `AI-skills/record-conventions.md` and record guides. If essential shared guidance is unavailable, say so; draft affected changes instead of saving. Continue independent, permitted work, including tasks limited to supplied files.

People establish findings, needs, fulfilment and decisions. Never invent records, IDs, sources or agreement. Respect access, consent and authorisation; cite exact sources and limits. Save only authorised changes, and report Saved and verified, Not saved or Save unverified. Follow [project health after record changes](../ai-guidance.md#refresh-an-existing-project-health-report) when saving project records; read-only work does not refresh it.

Start with the [task and working folder](../ai-guidance.md#start-with-the-task), then select only the relevant workflow and linked guidance:

- [Find and explain](../find-and-explain/SKILL.md) for a sourced answer or advice.
- [Capture or update records](../capture-or-update-records/SKILL.md) to document the team's work.
- [Check evidence and records](../check-evidence-and-records/SKILL.md) for evidence gaps, assessments, integrity, project health reports or framework upgrades.
- [Prepare a briefing](../prepare-a-briefing/SKILL.md) for refinement, playback, phase review or handover.
- [Import an existing project](../import-existing-project/SKILL.md) to bring existing material into the framework.

## Copy-and-paste example

> Use AI-skills/ucd-project-assistant/SKILL.md. Propose records for the decision and assumptions the team agreed in these playback notes, then show what evidence we still need.

## Work through the request

Connect each relevant discipline around the same user outcome using [guidance for experienced teams](../ai-guidance.md#advise-an-experienced-team). Carry the confirmed project folder and authorised source locations between workflows; never widen them silently. Carry the records' status, evidence, scope, gaps and [save result](../ai-guidance.md#check-status-and-what-was-saved) between workflows. Follow [withdrawal checks](../record-conventions.md#trace-withdrawn-evidence) where needed. Reconcile pending agreed changes with current records and later decisions before relying on or retrying them. Complete any [existing project health refresh](../ai-guidance.md#refresh-an-existing-project-health-report) once after all routed record saves, not after each subtask. Give one useful answer with exact references and decisions still requiring people.
