## Choose the check

Identify the claim, decision or area of the project in scope. Confirm the working folder, read the complete records needed and state which underlying sources you could check. [AI guidance](../../ai-guidance.md)

| Check | Method |
|---|---|
| Claim, proposal or decision | Verify the source and the users, versions and circumstances it covers. Flag gaps and discrepancies for people to interpret. [Check a claim](../../how-to/evidence-and-interpretation.md#check-a-claim) |
| User need assessment | Check the team's fulfilment judgement against its scope and evidence. Check the linked delivery decision separately. For totals, count each active recorded need once. [User needs guide](../../how-to/files/user-needs.md) |
| Project integrity | Use the project README to establish the framework version. Check structure, required fields, unique keys and exact links for the project's stage and the scope requested. [Check and repair project records](../../how-to/record-conventions.md#check-and-repair-project-records) |

Make a repair when the user authorises it and the correct change is established. Verify it after saving. Leave new findings, fulfilment judgements and decisions for the team.

Lead with the claim or decision affected. Cite what you checked and identify the most consequential gap and next source check. Report any repair and its verification.
