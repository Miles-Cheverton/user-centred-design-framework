# Find and explain

**Skill revision:** 2026-11-24.3

Use the matching revision of `ai-guidance.md` and `how-to/record-conventions.md`. If either is older or unavailable, report the gap before changing project records.

## Copy-and-paste example

> Use AI-skills/find-and-explain/SKILL.md with how-to/worked-service-handoff.md. In this fictional example, what did the team agree in DEC-202 about testing collection messages on web and telephone? Give the source references and any gaps that affect the answer.

## Answer from the project records

1. Establish the working folder and scope. Use the project README to find owning records. Treat files under `how-to/` and `AI-skills/` as guidance or examples unless the task explicitly asks to use them as example evidence. [AI guidance](../../ai-guidance.md#start-with-the-task)
2. Read the relevant full rows and resolve exact IDs, versions and replacements. Check **Pending changes** in project config for relevant unsaved changes to current records. When a match is missing in the table, check the owning sheet for rows outside it before concluding the record is absent. Trace claims to the underlying source where accessible. Check what the records establish about proposals, decisions and actual delivery. [Record conventions](../../how-to/record-conventions.md#canonical-relationships)
3. Give a direct answer with the owning records, source locations and gaps that affect it. Say whether you checked the underlying source or a reference. If raw research could answer the question, locate relevant observations and leave interpretation to the team. For fulfilment questions, use the team's assessment and the scope it covers. When a finding is Withdrawn, explain its recorded reason when relevant and flag any current claim that still relies on it. Follow the [status and save rules](../../ai-guidance.md#check-status-and-what-was-saved), including when using the output of another skill. [User needs guide](../../how-to/files/user-needs.md)

When asked for advice, use the [guidance for experienced teams](../../ai-guidance.md#advise-an-experienced-team). Compare the options against the user's goal and the strongest evidence for and against each. Explain which option you recommend, its trade-off and what could change your view. Cite professional guidance separately from project evidence when it affects the advice.
