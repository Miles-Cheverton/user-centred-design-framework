# Find and explain

## Copy-and-paste example

> Use AI-skills/find-and-explain/SKILL.md with how-to/worked-service-handoff.md. In this fictional example, what did the team agree in DEC-202 about testing collection messages on web and telephone? Give the source references and any gaps that affect the answer.

## Answer from the project records

1. Establish the working folder and scope. Use the project README to find owning records. [AI guidance](../../ai-guidance.md#start-with-the-task)
2. Read the relevant full rows and resolve exact IDs, versions and replacements. Trace claims to the underlying source where accessible. Check what the records establish about proposals, decisions and actual delivery. [Record conventions](../../how-to/record-conventions.md#canonical-relationships)
3. Give a direct answer with the owning records, source locations and gaps that affect it. Say whether you checked the underlying source or a reference. If raw research could answer the question, locate relevant observations and leave interpretation to the team. For fulfilment questions, use the team's assessment and the scope it covers.
