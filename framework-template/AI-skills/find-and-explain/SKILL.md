# Find and explain

For project work, open the specified project’s `_project-config.md` first. Resolve its **Working folder** using the [project boundary rules](../ai-guidance.md#confirm-the-project-boundary). Use only that confirmed folder and specifically authorised external sources; never search other projects by filename or ID. If the folder is unclear, ask for its exact path or URL; a task limited to supplied files may continue within that set. Resolve links from the canonical project path `AI-skills/find-and-explain/SKILL.md`, not the installed or copied skill location. Read the project’s `AI-skills/ai-guidance.md` [shared principles](../ai-guidance.md#shared-principles) and the applicable sections of `AI-skills/record-conventions.md` and record guides. If essential shared guidance is unavailable, say so; draft affected changes instead of saving. Continue independent, permitted work, including tasks limited to supplied files.

People establish findings, needs, fulfilment and decisions. Never invent records, IDs, sources or agreement. Respect access, consent and authorisation; cite exact sources and limits. Save only authorised changes, and report Saved and verified, Not saved or Save unverified.

## Copy-and-paste example

> Use AI-skills/find-and-explain/SKILL.md. Trace [user need ID] back to its source. Tell me exactly what the evidence supports, what is uncertain and where I can check it.

## Answer from the project records

1. [Confirm scope and owners](../ai-guidance.md#start-with-the-task). Read the relevant [record guide](../../how-to/README.md#record-guides) and [applicable records](../ai-guidance.md#read-workbooks-completely-enough-for-the-task).
2. [Follow exact relationships](../ai-guidance.md#follow-exact-relationships), including sources, status, versions and relevant pending changes. Use the [withdrawal lookup](../record-conventions.md#trace-withdrawn-evidence) where needed and [fulfilment and verification rules](../ai-guidance.md#assess-whether-needs-are-met) for assessment questions.
3. [Ground the answer](../ai-guidance.md#ground-claims) in actual sources, distinguish what was checked from referenced-only material, current from historical and agreement from verification. Lead with the answer, then references, limits and any human decision still needed. Where people have not reached a conclusion, identify relevant observations without inventing one.

When advice is requested, use [the guidance for experienced teams](../ai-guidance.md#advise-an-experienced-team); compare options, trade-offs and the evidence that would change the choice.
