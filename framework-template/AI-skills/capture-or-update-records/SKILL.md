# Capture or update records

Use the confirmed project folder (normally containing `document-tracker.xlsx`), not the installed or copied skill location. Resolve links from the canonical project path `AI-skills/capture-or-update-records/SKILL.md`. Read the project’s `AI-skills/ai-guidance.md` [shared principles](../ai-guidance.md#shared-principles) and the applicable sections of `AI-skills/record-conventions.md` and record guides. If essential shared guidance is unavailable, say so; draft affected changes instead of saving. Continue independent, permitted work, including tasks limited to supplied files.

People establish findings, needs, fulfilment and decisions. Never invent records, IDs, sources or agreement. Respect access, consent and authorisation; cite exact sources and limits. Save only authorised changes, and report Saved and verified, Not saved or Save unverified.

## Copy-and-paste example

> Use AI-skills/capture-or-update-records/SKILL.md. Propose updates from the team’s notes. Check them against the supplied transcript and project records. Give exact sources, fill in verified details and flag gaps or disagreements for us to check.

## Propose or update each record

1. Confirm the [task and working folder](../ai-guidance.md#start-with-the-task), permitted sources and current record owner in the [document tracker](../../document-tracker.xlsx). Read the relevant [record guide](../../how-to/README.md#record-guides), [key/classification rules](../record-conventions.md#stable-identifiers-and-owner-lookup) and [relationships](../record-conventions.md#canonical-relationships).
2. [Check applicable records](../ai-guidance.md#read-workbooks-completely-enough-for-the-task) for existing matches, relevant versions or replacements. Keep the existing ID for the same record. Verify the next unused ID for a new record; add in an empty named-table row per the [editing rules](../record-conventions.md#edit-records).
3. Start from what people concluded or agreed, check against approved sources and propose the exact fields and citations. Point out useful passages, matches and unresolved differences without changing the team's meaning. With raw material alone, capture requested observations, not findings or needs. Reviewed findings require agreed wording and checked sources; otherwise Draft. Cite a session and exact source/locator; reuse or add a [DOC entry](../../how-to/research-and-evidence.md#register-a-source) when a non-session citation needs one.
4. Follow [save and report](../ai-guidance.md#save-and-report). Save only as authorised and verify the actual destination can represent the agreed change. Preserve workbook controls, unrelated and [extra columns](../ai-guidance.md#read-and-preserve-extra-workbook-columns). Return exact proposed fields if blocked; continue independent compatible changes.

For specific tasks:

- **Research and meeting follow-up:** use the team's [research debrief](../../how-to/research-and-evidence.md#human-analysis-before-documentation) or [meeting follow-up](../../how-to/research-and-evidence.md#capture-what-changed-in-a-meeting). Retain material alternatives and rationale in Decisions. Separate agreed and unresolved parts; a partial decision replacement records the complete continuing position and related links. Link the exact [research materials](../../how-to/research-and-evidence.md#discussion-guides-surveys-and-whiteboards), noting actual coverage.
- **Withdrawals:** preserve the ID, permitted reason and history. Record the agreed withdrawal and [trace affected claims](../record-conventions.md#trace-withdrawn-evidence); flag for team reassessment without inventing a new judgement.
- **Needs and verification:** flag overlapping needs for the team; use [replacement rules](../record-conventions.md#references-blanks-and-replacements) for an agreed merge. Use [assess whether needs are met](../ai-guidance.md#assess-whether-needs-are-met) to keep existence, assessed fulfilment, intended delivery and current verification distinct.

For cross-disciplinary work use the [guidance for experienced teams](../ai-guidance.md#advise-an-experienced-team). Keep suggestions separate from agreed changes.

## File a chat attachment

Use the [source guide](../../how-to/research-and-evidence.md#file-a-source) to establish the approved destination and exact source version. Ask only about placement, permission or ambiguity that matters. Reuse a verified identical source; retain different versions separately and in original format. Verify the file before adding or reusing its source entry if needed. If blocked, say which part succeeded; [report the save result](../ai-guidance.md#check-status-and-what-was-saved) with destination, record and citation if verified. Reuse completed steps on retry.
