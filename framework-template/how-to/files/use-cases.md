# Use cases

**Working file** [use-cases.xlsx](../../use-cases.xlsx)

## First capture

Use a UC ID and name the user’s goal. Select **Current experience** or **Proposed experience** and start with **Draft**.

| Field | What to enter |
|---|---|
| ID | Stable UC ID. |
| Use case | A short name for the goal, such as Rearrange a repair visit. |
| User group IDs | Exact UG IDs for the people taking part. |
| User need IDs | Exact UN IDs where related needs are established. |
| Represents | Current experience or Proposed experience. |
| Interaction | What starts the interaction, what needs to be in place, user and service steps, important alternatives or recovery routes, and the intended result. Cite EV or FND records for observed behaviour. Link a journey or prototype when it provides context. |
| Status | Draft, Reviewed or Superseded. Reviewed means the team checked the description. Check **Represents** before treating it as current behaviour. |

Keep significant earlier cases. For a superseded case, record exact replacement UC IDs in **Interaction** or flag a missing replacement.
