# Participants

**Working file (via document tracker)** [participants.xlsx](../../document-tracker.xlsx)

## First capture

Give each participant a **Participant ID** and record their **User group IDs** before linking their sessions.

## Fields

| Field | What to enter |
|---|---|
| Participant ID | Unused code such as `PAR-001`. Reuse the code across sessions when the agreed research arrangements permit linking them. |
| User group IDs | One or more exact UG IDs for the groups the participant can represent. Check the group's role and circumstances recorded in each session’s own notes before counting that session as coverage. |

Keep names, contact details and any identity key in separately restricted storage. Participant codes can still identify people when linked to records such as consent or recordings. Control access and follow agreed retention and withdrawal arrangements. Record relevant recruitment characteristics in approved recruitment or session records. A participant can represent different groups in different sessions. Keep the role and group IDs they represented at the time in the session’s existing notes. Changes to their participant record leave earlier session coverage as recorded.

[GDS guidance on participant privacy](https://www.gov.uk/service-manual/user-research/managing-user-research-data-participant-privacy)
