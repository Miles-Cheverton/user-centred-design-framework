# Research questions

**Working file (via document tracker)** [research-questions.xlsx](../../document-tracker.xlsx)

## First capture

Enter an **ID** and **Question**. Write a question the research can answer, such as “How do applicants currently find out when a decision is likely?”

## Fields

| Field | What to enter |
|---|---|
| ID | Stable research question ID, for example `RQ-001`. |
| Question | What the team needs to learn. Leave room for an unexpected answer. |
| Decision informed | What the team will decide or understand using the answer. |
| Status | Open, Investigating, Answered, Superseded or Withdrawn. Mark Answered when a current Reviewed finding that cites the RQ ID supports the answer. Use Withdrawn when the team confirms that the question itself is no longer needed and has no replacement. |
| Superseded by | Exact replacement RQ IDs. Flag an unknown replacement for a Superseded question. Leave blank for a Withdrawn question. |

Plan to answer the question in time for the decision. Cite the RQ ID in **Evidence and source** in [findings](../../document-tracker.xlsx), including any limits on the answer.

To check an Answered question, find the current Reviewed findings that cite its RQ ID and verify that they still support an answer. If evidence is withdrawn or invalidated, flag the question for the team even when another finding still exists. Add the dated review note in **Decision informed** when authorised. Keep the recorded status until review. If an answer is no longer supported, the team can return the question to Open or Investigating.

For a Withdrawn question, retain the ID and wording. In **Decision informed**, record the date and reason the team stopped pursuing the question and any related DEC ID. Preserve its historical links.
