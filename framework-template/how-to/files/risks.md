# Risks

**Working file (via document tracker)** [risks.xlsx](../../document-tracker.xlsx)

## First capture

Enter an **ID** and **Risk**. Describe the cause, what might happen and its effect. For example, “Recruiting only online may miss people who need help by phone, leaving barriers undiscovered.”

## Fields

| Field | What to enter |
|---|---|
| ID | Stable risk ID, for example `RSK-001`. |
| Risk | The uncertain event and its effect on the project or service. |
| Current likelihood | Not assessed, Low, Medium or High. Rate using the team’s criteria and timeframe. Use Not assessed until agreed. |
| Current impact | Not assessed, Low, Medium or High. Rate the consequence under the same criteria. Use Not assessed until agreed. |
| Response | Use **In place** for existing controls and **Next** for the planned action and timing. |
| Owner | Person or role accountable for the risk and response. |
| Review date | Next substantive review, when known. |
| Status | Open, Accepted, Occurred or Closed. |

Rate the risk using controls already in place and checked. Review after new evidence or changes to controls, including for accepted risks. If a risk occurs, mark it Occurred. Record what happened in **Response** and link to the issue or action the owner is following up.
