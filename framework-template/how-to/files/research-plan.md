# Research plan

**Working file (via document tracker)** [research-plan.xlsx](../../document-tracker.xlsx)

## First capture

Enter the round’s **ID** and **Research question IDs**. Link one short protocol for the method, lead, start date when known and arrangements for the team debrief. Link guides or materials you already have.

## Fields

| Field | What to enter |
|---|---|
| ID | Stable round ID, for example `RND-001`. |
| Research question IDs | One or more RQ IDs the round will address. |
| User group IDs | Planned UG IDs. For a study without participants, leave blank and explain the scope in the protocol. |
| Status | Proposed, Preparing, Ready, In progress, Analysing, Complete or Cancelled. Mark Ready when the team has the materials, access and arrangements to run the round. Use Analysing while substantive evidence awaits the team’s analysis. |
| Protocol path | The protocol for this round, for example `research/RND-001/protocol.md`. |

## Close the round

Use the protocol’s **Team debrief** section to note the team’s reasoning and open questions or link existing notes. Mark Complete after the team has reviewed the evidence and recorded its findings. If it could draw no conclusion, record why in the debrief and keep unanswered questions open. Use [sessions](../../document-tracker.xlsx) to check who took part and [findings](../../document-tracker.xlsx) for what the team concluded.
