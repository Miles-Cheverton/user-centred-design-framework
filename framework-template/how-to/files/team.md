# Team

**Working file (via document tracker)** [team.xlsx](../../document-tracker.xlsx)

## First capture

Enter an **ID** and **Name** for each team member or role. Use **Vacant** for an unfilled role.

## Fields

| Field | What to enter |
|---|---|
| ID | Stable team member or role ID, for example `TM-001`. |
| Name | Person, team or Vacant. |
| Job title | Formal title, when known. |
| Email | Work address, where appropriate. |

Update the directory as people join, leave or change roles. Record leads, owners and decision-makers in the records for the actual work. See [human analysis before documentation](../evidence-and-interpretation.md#human-analysis-before-documentation).

[GDS guidance on service team roles](https://www.gov.uk/service-manual/the-team/what-each-role-does-in-service-team)
