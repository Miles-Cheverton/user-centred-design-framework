# Prototypes

**Working file** [prototypes.xlsx](../../prototypes.xlsx)

## First capture

Enter **ID** and **Version** when a prototype is used in research, informs a significant decision, receives substantive review or is handed over. Retain what the team learned from disposable sketches in [findings](../../findings-and-observations.xlsx).

## Fields

| Field | What to enter |
|---|---|
| ID | Stable PRT ID. Keep it for revisions and use another for a distinct prototype. |
| Version | The retained version, for example `v1`. Identify it with both values, such as `PRT-001 v1`. |
| Link | Link directly to the exact retained version, or to a short note that opens it. Add the link before anyone relies on the version. |
| Status | Draft, Ready for research, Tested, Selected, Discarded or Superseded. Selected records a design choice. Record deployment evidence in its own source. |

## Check the retained version

Use the link that opens the version in the format your team used. It could be a Figma flow, a coded prototype, slides or photos of a paper prototype. Keep local files in [prototypes](../../prototypes/) if useful. Add a version folder when there are files to store.

If a link will show later edits, retain the state you used through a saved version, a copy or a dated capture in approved storage. A capture can show screens or steps. Use the original version or session evidence to establish what people could do.

Add a short note when the link needs context. In the note, link to the exact artefact and give the starting point, relevant setup, what the prototype does and what it simulates or leaves out. Include related journey versions or decision IDs when useful. You can link to this note from the workbook. If you cannot open the prototype, state what you could check from the note or capture.

Link [sessions](../../research-sessions.xlsx) to every prototype version actually shown. After the team analyses the results, cite the relevant version in **Evidence and source** for each observation or finding. Retain any discarded versions that explain significant learning or decisions.
