## First capture

Use a TERM ID and record the preferred **Term**.

Before using the entry, write a **Definition** that explains what the term means in this project. Include alternative names or abbreviations people might search for.

**Example** A research round is a planned set of activities that address related questions. Some teams call it a study round.

Keep the ID when improving wording. If the meaning changes, explain what changed and update the affected records.

[ONS guidance on plain language](https://service-manual.ons.gov.uk/content/writing-for-users/plain-language)
