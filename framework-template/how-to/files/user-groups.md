# User groups

**Working file (via document tracker)** [user-groups.xlsx](../../document-tracker.xlsx)

## First capture

Enter an **ID** and a recognisable **Name**. Describe people through how they use, provide or experience the service. Include supported channels and relevant access barriers.

## Fields

| Field | What to enter |
|---|---|
| ID | Stable group ID, for example `UG-001`. Research and user needs use this ID. |
| Name | Short group name, such as “Applicants waiting for a decision”. |
| Description | Who belongs and what matters about their circumstances or role. Add an EV or FND reference where helpful and flag provisional descriptions. |

Refine the description as evidence develops. Keep the ID for the same group. For a material split or combination, keep the earlier rows and description. Add the date and reciprocal UG IDs in **Description**, for example “Split into UG-014 and UG-015 on 2026-11-20” and “Split from UG-003 on 2026-11-20”. For a combination, link the earlier groups to the combined group and vice versa. Cite any related DEC ID. Keep historical links to the groups represented at the time and ask the team to review which current records should use the new IDs.

[GDS guidance on learning user needs](https://www.gov.uk/service-manual/user-research/start-by-learning-user-needs)
