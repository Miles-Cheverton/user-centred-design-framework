# Success measures

**Working file** [success-measures.xlsx](../../success-measures.xlsx)

## First capture

Give the measure a MET ID and a clear name. Link the outcome and define how to calculate the measure before using it.

| Field | What to enter |
|---|---|
| ID | Stable MET ID. |
| Measure | What you will track, such as the proportion of repair appointments successfully rescheduled. |
| Outcome IDs | The OUT IDs this measure helps assess. |
| Baseline | Starting value, period and supporting EV IDs. Use Not yet established if unknown. |
| Target | Desired value or direction, by when and why. |
| Source and method | Exact DOC sources or SES references, with version and location. Describe the calculation, unit, population, period and exclusions. Add owner and review timing if useful. |
| Results | Link to the maintained result and give the date, filters or snapshot and relevant EV IDs. Note interpretation and link the DEC ID for a material change. |

Before reporting improvement, check that the baseline and results cover comparable populations, periods and methods. Put DEC references with the field they affect when the team changes a measure, target or interpretation.
