# How to use this framework

Use the framework to organise research, user needs and decisions so people and AI assistants can work from the same information. Read [why the framework exists](../README.md#why-the-framework-exists).

Copy [the template](../template/) to your approved project workspace. Open the [project README](../template/README.md), name the service, and add the locations your team already works in. If you are starting from scratch, write the [problem statement](../template/how-to/files/problem-statement.md) first. If you are joining work in progress, start with the decision or question the team is working on today.

Use the [task guide](../template/how-to/README.md) to find the files for that task. Begin with the first capture in the relevant file guide. Add the rest when the team needs to share, review or rely on the record.

| When you need to… | Start here |
|---|---|
| Record learning after a research session | [Capture learning](../template/how-to/README.md#capture-learning) |
| Work out what is agreed, open or ready to hand over | [Prepare a review](../template/how-to/README.md#hand-over-or-prepare-a-review) |
| Check a claim from a playback or report | [Follow the worked service handoff](../template/how-to/worked-service-handoff.md#trace-a-playback-claim-back-to-its-source) |

With AI, name the task, identify the files and say whether you want a check, a draft or a saved update. For research, give it the conclusions the team reached and ask it to check the wording or references against the sources. Choose a [skill for the task](../template/skills/README.md) or a [prompt for a project question](../template/ai-prompts/README.md).

To bring an existing project up to date, check the [changelog](CHANGELOG.md) for changes that apply to your records.
